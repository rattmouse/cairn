# Markdown Reference

What this editor renders.

**Bold**, *italic*, ~~struck through~~, `inline code`, and bare URLs like
https://example.org which become links on their own.

## Lists

- Bullets
- With a second line that
  continues the item
1. Ordered
2. Also ordered
- [ ] Unchecked task
- [x] Checked task

## Quotes and callouts

> An ordinary blockquote.

> [!NOTE]
> A callout, which gets its own colour.

## Code

```javascript
const slug = s => s.toLowerCase().replace(/[^a-z0-9]+/g, "-");
```
