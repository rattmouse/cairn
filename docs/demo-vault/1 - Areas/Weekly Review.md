# Weekly Review

Friday afternoon, twenty minutes, same four questions.

1. What actually moved this week?
2. What is blocked, and on whom?
3. What did I say yes to that I should not have?
4. What is the single next action on each project?

> Anything that survives three reviews untouched is not a project. It is a wish, and it belongs in [[Someday Maybe]].
